# re-Linked — Твоя персональная стартовая страница

**Локальный менеджер закладок, превращающий ссылки в визуальную Kanban-доску.**
Без аккаунтов. Без облака. Без слежки. Всё живёт на твоём устройстве в одном файле `index.html`.

## Что такое re-Linked?

re-Linked заменяет встроенную панель закладок браузера на Kanban-доску с перетаскиванием. Колонки, категории и ссылки организованы так, как удобно тебе — без лишних движений, с полным контролем.

**Ключевые принципы:**

- **Офлайн в первую очередь** — все данные в IndexedDB браузера. Ни сервера, ни синхронизации, ни интернета.
- **Портативность** — собранное приложение — один файл `index.html`. Копируй куда угодно: на флешку, в бекап, по почте.
- **Приватность** — ничего не покидает твоё устройство. Твои ссылки, домены и статистика использования — только твои.
- **Кастомизация** — светлая/тёмная тема с 6 цветовыми оттенками. Английский и русский языки.

## Возможности

### Kanban-доска

- **Колонки** — высокоуровневые группы (Работа, Личное, Инструменты, Медиа…)
- **Категории** — подгруппы внутри колонок (Frontend, Backend, Новости, Музыка…)
- **Избранное** — компактные карточки с иконкой, названием и счётчиком переходов

### Drag & Drop

- Перетаскивай колонки, категории и ссылки.
- Адаптивность: горизонтальная прокрутка с привязкой на мобильных, скролл колёсиком на десктопе.

### Импорт / Экспорт

- Экспорт доски в JSON (полный бекап или выбранные категории).
- Импорт из JSON: режим слияния (добавляет новое, пропускает дубликаты) или замены (полная очистка перед импортом).
- Предпросмотр импорта — покажет, что именно изменится.

### Обнаружение дубликатов

- Добавляешь ссылку, которая уже есть? Приложение покажет, где именно лежит оригинал.
- Системная подсветка дубликатов: все копии одной ссылки визуально подсвечиваются по всей доске.

### Редактор доменов и ссылок

- Управляй доменами и ссылками вне доски.
- Поиск, смена иконок (загрузка из файла), редактирование URL и названий.
- Каскадное удаление: удаляешь домен → удаляются все связанные ссылки и избранное.

### Счётчик переходов

- Каждая ссылка считает переходы. Узнай, чем ты реально пользуешься.

### Фавиконы

- Автоматическая загрузка иконок сайтов через несколько стратегий: сервис Google, прямой `/favicon.ico`, парсинг HTML.
- Загрузка своих иконок для доменов.

### Режим приватности

- Нажми `Ctrl+\` чтобы мгновенно скрыть содержимое доски под матовым стеклом. Повторное нажатие, клик или `Escape` — возврат к обычному виду.

### Темы

- Светлый / Тёмный режим с 6 акцентными оттенками: Сланец, Зелёный, Жёлтый, Красный, Фиолетовый, Серый.

## Установка и запуск

### Для пользователей

1. Скачай последний `re-Linked.zip` со страницы [Releases](https://github.com/i0FFLINE/re-linked/releases).
2. Распакуй в любое место на диске.
3. Открой `index.html` в браузере. Без сервера, без установки.

Установи как страницу новой вкладки: расширение вроде «New Tab Redirect» и укажи путь `file:///путь/к/index.html`.

---

## Ограничения `file://`

Запуск через `file:///` накладывает ограничения браузера:

| Возможность         | Статус        | Примечания                                                |
| ------------------- | ------------- | --------------------------------------------------------- |
| IndexedDB           | ✅ Полностью  | Все данные хранятся локально                              |
| Hash-роутинг        | ✅ Работает   | Используется `createWebHashHistory`                       |
| Импорт/Экспорт JSON | ✅ Работает   | Диалоги открытия/сохранения файлов                        |
| Загрузка фавиконов  | ⚠️ Ограничено | Кросс-доменные запросы блокируются в некоторых браузерах  |
| Копирование в буфер | ⚠️ Ограничено | Требуется жест пользователя, не все браузеры поддерживают |
| `window.open()`     | ✅ Работает   | Ссылки открываются в новых вкладках                       |
| Внешние шрифты      | ✅ Работает   | Встроены как woff2 в сборку                               |
